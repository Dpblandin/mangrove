# Marques des intégrations

`gitlab.svg` provient du [catalogue SVG GitLab](https://gitlab.com/gitlab-org/gitlab-svgs/-/blob/main/illustrations/gitlab_logo.svg). Les chemins et couleurs sont conservés ; les dimensions intrinsèques passent de 25 × 24 à 100 × 96 pour le rendu HiDPI. L’image est embarquée dans le binaire et partagée entre les vues, sans requête réseau.
