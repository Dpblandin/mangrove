# Marques des intégrations

`gitlab.svg` provient du [catalogue SVG GitLab](https://gitlab.com/gitlab-org/gitlab-svgs/-/blob/main/illustrations/gitlab_logo.svg). Les chemins et couleurs sont conservés ; les dimensions intrinsèques passent de 25 × 24 à 100 × 96 pour le rendu HiDPI. L’image est embarquée dans le binaire et partagée entre les vues, sans requête réseau.

La licence du catalogue est conservée dans `LICENSE.gitlab`. GitLab et son logo sont des marques de GitLab Inc. Voir aussi les [ressources officielles](https://about.gitlab.com/press/press-kit/).

`bitbucket.svg` provient du logomark sans tuile fourni dans [`@atlaskit/logo` 21.4.4](https://www.npmjs.com/package/@atlaskit/logo/v/21.4.4), fichier `dist/es2019/legacy-logos/bitbucket/icon.js` du [paquet officiel Atlassian](https://registry.npmjs.org/@atlaskit/logo/-/logo-21.4.4.tgz). Le chemin et le `viewBox` 32 × 32 sont conservés ; le bleu `#357DE8` correspond à l’apparence `brand` du thème sombre dans `legacy-logos/get-colors-from-appearance.js`. Les dimensions intrinsèques passent à 128 × 128 pour le rendu HiDPI. L’image est embarquée sans requête réseau, pour Bitbucket Cloud et Server/Data Center.

Le copyright Atlassian et la licence Apache 2.0 sont conservés dans `LICENSE.bitbucket`. Bitbucket et son logo sont des marques d’Atlassian. Voir les [ressources officielles](https://atlassian.design/foundations/logos) et les [conditions d’usage des marques](https://www.atlassian.com/legal/trademark).
